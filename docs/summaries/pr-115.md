# PR #115 — Threads: retry instead of failing when the gateway refuses on balance

**Status:** merged into `main` (2026-09-27) · **Author:** @daraijaola · **Branch:** `capy/threads-402`
**Size:** +105 / −17 across 5 files.

## In one sentence

When the inference gateway rejects a turn with HTTP 402 (insufficient balance), moonlet now shrinks the request and retries instead of failing — and computers gain scripted Playwright browsing via a new `step` command.

## What changed

### 1. Graceful 402 retry (`src/moonlet/thread-agent.ts`)

The gateway reserves the worst-case cost of a request up front (attached images, output token limit) against the owner's balance. Previously a 402 meant the turn simply failed. Now it degrades gracefully:

1. **Swap images for descriptions.** If any message carries an image, each image is replaced with a detailed text description produced by the cheap vision model (Gemini Flash) via the extracted `describe()` helper, and the turn retries. This drops the vision reservation from the request.
2. **Halve the output limit.** If there are no images left to swap, `max_tokens` is halved (floor of 1024) and the call retried, shrinking the up-front reservation.
3. **Clear failure only as a last resort.** Only when neither fallback remains does the turn fail, with a message telling the owner to pick a cheaper model or activate more CREDIT.

Retries reuse the same loop step (`step--`), so fallbacks don't burn the turn budget.

### 2. Scripted browsing with Playwright (`computers/desktop/`)

Computers now ship `playwright-core` and a `step` shell command that runs Playwright code against the visible Chromium over CDP:

```sh
step "await page.goto('https://example.com'); await page.getByRole('button', {name: 'Sign in'}).click()"
```

- `step.js` connects to the running browser (`connectOverCDP`), exposes `page`, `context` and `browser`, keeps the browser open between steps, and prints the resulting page URL or the first error line.
- The moonlet prompt now teaches `step` as the primary way to drive complex web flows, with `browser_open` / `browser_read` / `browser_click` kept as a quick alternative, and instructs falling back to a site's public API when a bot check won't clear.
- Chromium launches with `--disable-blink-features=AutomationControlled` to reduce bot detection.

### 3. Tab hygiene (`computers/desktop/agentd.py`)

- `_close_extension_tabs()` closes MetaMask's onboarding tab on first launch so it never steals focus from the page being worked on.
- `_page_ws()` now prefers non-extension tabs and activates the chosen tab before returning its debugger URL, so screenshots and CDP actions land on the right page.

### 4. Model metadata (`src/moonlet/thread-models.ts`)

Minor accompanying adjustment to the thread model list.

## Why it matters

- Owners with low balance get a completed turn at reduced fidelity instead of a hard failure.
- Agents can automate real web flows (multi-step forms, SPAs) far more reliably than element-number clicking alone.
